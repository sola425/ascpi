# Public-project inspiration

Reviewed on 6 November 2026 using the repositories' public README files:

| Project | Ideas considered | Labwise implementation |
| --- | --- | --- |
| [AnkiDroid](https://github.com/ankidroid/Anki-Android) | Active recall, flashcards, review statistics, night mode, spaced repetition | Think-before-flip cards, review ratings, due queues, subject progress, and dark mode |
| [FSRS4Anki](https://github.com/open-spaced-repetition/fsrs4anki) | Separating review scheduling from content, using history to guide future review | A separate, tested scheduling module with explicit intervals. Labwise does not implement FSRS, its optimizer, or personalized memory predictions. |

No project code, graphics, branding, or deck content was copied. These sources inspired general study patterns. Labwise's design, scheduler, interface, and teaching examples are implemented independently. The PDF is the file supplied by the user, not downloaded from a public deck or repository.
