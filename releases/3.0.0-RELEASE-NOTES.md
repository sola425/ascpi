# Labwise 3.0.0

A signed offline Android release of the MLS study app.

- Android 8.0+ with an up-to-date Android System WebView.
- Complete 434-page uploaded PDF, including color plates.
- 1,280 extracted question/answer pairs across 12 subjects.
- 54 separately written simple explanations with memory hooks.
- Practice, flashcards, review scheduling, deferred-feedback exams, saved questions, progress and backups.
- Native offline PDF reading with page jumps and zoom.
- Native Android file pickers for JSON imports and exports.
- No account, server, Internet permission, or shared-storage permission.

The remaining 1,226 question rationales are source text, not completed simple-language rewrites. OCR-derived content and older clinical recommendations still require editorial verification. Questions with ambiguous extraction remain in the complete PDF rather than scored practice.

The APK signature and package checks passed. Browser and Android-bridge tests passed. Android device/emulator execution was not verified because hardware virtualization is unavailable here. No Google Play publication is claimed.
